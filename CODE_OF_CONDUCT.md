# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind and respectful, assume good intent, welcome newcomers, and keep criticism about the work rather than the person. Harassment, discrimination and personal attacks aren't tolerated.

## Reporting a problem

Use GitHub's **Report content** option on the comment, issue or pull request concerned and send the report to the repository's maintainers. The maintainer, Vino Veeraiyan ([@vinovee](https://github.com/vinovee)), reads every report and handles it in confidence. If the problem isn't tied to anything on GitHub, open an issue asking for a private contact, without details, and the maintainer will get in touch.
